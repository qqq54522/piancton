# 卖点智库全界面低保真流程图

这份图不是“业务流程概括图”，而是按当前项目真实页面和关键子界面整理出来的低保真界面流程图。每个框代表一个页面、弹窗、面板或页面内部子界面，箭头表示用户操作、页面跳转、后台治理输入或日志沉淀。

## 覆盖的界面

| 区域 | 覆盖界面 |
| --- | --- |
| 入口与应用外壳 | 登录页、鉴权守卫、应用 Layout、角色导航、404 兜底页 |
| 业务用户主流程 | 素材库首页、手动筛选抽屉、搜索加载/错误态、搜索结果区、素材详情业务视图、预览/下载、素材库 Agent、分享链接入口 |
| 设计师 / 管理员素材维护流 | 上传主图弹窗、上传前 AI 话术生成、素材详情设计师视图、AI 分析面板、素材工作台、版本/删除弹窗、回收站 |
| 管理员后台治理 | 卖点管理、渠道管理、API 中心、搜索运营、身份码管理、使用统计、用户管理、审计日志 |

## 核心读图规则

```text
身份码 / 分享链接
→ 先走确定性查找
→ 直接进入素材详情
→ 不让模型猜

普通自然语言搜索
→ 进入 API 中心调度模型
→ 理解体系、卖点、证明点
→ 受 accepted 人工关系约束
→ 返回可信素材和解释

素材库 Agent
→ 读取图片上下文、卖点关系和素材话术
→ 解释图片为什么能用、怎么用、怎么讲
→ 不直接写入业务事实
```
