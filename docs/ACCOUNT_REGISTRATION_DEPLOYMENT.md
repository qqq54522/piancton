# 自助注册更新说明

更新日期：2026-09-16。新人 Agent 引导与账号头像已部署到云端；业务端每日昨日反馈已在本地完成，等待下一次云端更新。

## 使用流程

1. 打开登录页，点击“还没有账号？注册账号”。
2. 填写账号（去除首尾空格后 3–100 个字符）、密码（8–200 个字符，不能全为空格）和确认密码；可选六个预设头像或上传自己的图片。
3. 注册成功后返回登录，账号自动保留；使用新密码登录。如果选择了自定义头像，登录后保存到该账号。以后可从账号头像菜单更换。
4. 首次进入图库会出现新版引导，说明如何向右侧 Agent 连续提问、按渠道浏览和找素材卡。
5. 注册次日起，业务账号每天第一次进入会强制填写一次昨日使用反馈；当天完成后刷新、重新登录或换设备都不会重复。

自助注册账号立即启用，默认普通业务权限，可以浏览、搜索和下载素材。设计师及管理员权限由现有管理员在用户管理中分配。当前为开放注册，任何可以访问站点的人均可注册；未加入邀请、审批、短信或飞书登录流程。账号沿用现有大小写敏感规则。重复账号不会覆盖原账号。

## 更新服务器

将本次代码同步至服务器现有部署目录（通过项目正常 Git 发布流程或代码包），保留服务器 `.env` 与数据卷，然后在该目录执行：

```sh
docker compose up -d --build backend web
docker compose ps
```

后端启动时自动应用迁移 `20260916_0043`；`0042` 添加可空的用户头像元数据，`0043` 添加可空的每日反馈完成日期，不改已有账号、素材数据或搜索索引。自定义头像使用已配置的本地或 TOS 私有存储，放在独立的 `account-avatars` 路径。保留现有 `.env` 和数据卷；不要执行 `docker compose down -v`。

## 上线验收

- 未登录访问登录页，可切换注册和登录。
- 新账号注册成功，使用新密码登录后可浏览素材。
- 注册预设头像在顶部账号入口显示；自定义头像只有账号本人能读取，账号菜单可更换。
- 首次使用弹窗没有旧顶部搜索框提示，可看到 Agent 提问与渠道找图示例。
- 用创建日期早于今天的业务账号登录，会出现昨日反馈表；不能点背景或按 Escape 跳过，确认完成后当天不再出现。
- 新注册当天、管理员和设计师不出现昨日反馈表。
- 重名账号、短密码、确认密码不一致会被拒绝。
- 管理员用户管理可看到新账号；新账号无法访问管理后台或上传素材。
- 现有管理员和普通用户仍能登录。
