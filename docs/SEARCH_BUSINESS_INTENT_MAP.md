# 搜索业务话术词库与意图簇映射

版本：2026-06-28  
用途：把业务原文档中的长文案、家长痛点、卖点表达，整理成搜索系统可使用的意图簇。  
适用范围：智能搜索意图理解、标签归一、语义总结匹配、搜索排序和评测集建设。

这份文档解决的问题不是“再多加几个关键词”，而是让系统知道：

> 用户输入的一整句业务话术，真实是在找哪个业务卖点、哪个体系、哪类图片。

当前测试暴露出的核心问题：

- 明确词能搜到，例如 `错题本`、`拍题`、`专家规划`。
- 换成真实业务话术后，系统能理解部分字面意思，但没有稳定归一到核心标签。
- 即使识别到了相关标签，也常把正确图片放进 C 级兜底，继续召回大量泛学习素材。

因此后续搜索不应该只看标题和标签，也要深度利用图片的 `image_summary`、隐性内容标签、业务标签理由和推荐搜索词。

---

## 1. 搜索意图理解原则

### 1.1 先识别“卖点意图”，再做召回

用户说的往往不是标签名，而是家长痛点或业务文案。

示例：

| 用户话术 | 系统应归一到 |
|---|---|
| 整理练习册上的错题太麻烦，还容易忘 | 同步自学体系 > AI错题本 |
| 孩子拿手机拍题只抄答案，考试还是不会 | 同步自学体系 > AI拍题精学 |
| 出卷人、编教材的人设计课程，不走弯路 | 同步培养体系 > 专家规划 |
| 家长叫不动、管不住，一管就吵架 | 同步伴学体系 > 真人老师督学 |
| 不知道孩子每天学了啥、学了多久 | 同步伴学体系 > 学情报告反馈 |

### 1.2 精准搜索允许少结果

当 query 已经明确归一到某个强意图时：

- 强相关图片只有 1 张，就返回 1 张。
- 不要为了补满 15 张，把 C 级兜底结果铺满页面。
- C 级兜底只适合“拓展推荐”，不应该污染主搜索结果。

### 1.3 语义总结是核心匹配字段

图片的 `image_summary` 不只是展示字段，应参与语义匹配。

推荐做法：

- 查询侧生成 `query_intent_profile`：痛点、功能、场景、用户角色、排除项。
- 图片侧使用 `image_summary + content_tags + business labels + recommended_search_words` 组成 `image_intent_profile`。
- 匹配时优先判断“概念是否一致”，而不是只判断是否出现同一个词。

例如：

```text
query: 家长怕孩子拍题只抄答案，考试不会
应匹配概念：拍题后分步讲解、引导思路、不是直接给答案
强匹配图片摘要：手机拍摄题目后，系统展示分步讲解和解题思路，引导学生理解题型
弱匹配图片摘要：学生拿手机看学习页面
排除图片摘要：只展示最终答案、普通课程列表、普通错题列表
```

## 2. 意图簇结构

每个意图簇包含：

- 核心标签：系统中的稳定归属。
- 原文档核心卖点：业务原文里的本意。
- 用户常见话术：用户可能输入的自然语言。
- 家长痛点表达：更模糊、更真实的搜索句。
- 语义总结匹配信号：图片摘要中出现哪些概念时应加权。
- 排除/降权信号：哪些看似相关但不该强匹配。
- 示例 query：用于搜索评测集。

## 3. 同步自学体系

### 3.1 AI错题本

核心标签：`同步自学体系 > AI错题本`  
原文档核心卖点：错题一拍上传，自动整理到 AI 错题本，分析错因，推荐同类题，帮助孩子复习和迁移。

用户常见话术：

- 错题本
- AI错题本
- 错题整理
- 错题归纳
- 错因分析
- 错题复习
- 上传错题
- 录入错题
- 错题自动整理
- 同类题训练
- 变式训练

家长痛点表达：

- 整理日常练习册上的错题太耽误功夫。
- 错题抄下来很麻烦，后面还容易忘。
- 孩子这道题会了，换个题型还是错。
- 不想让孩子盲目刷卷子。
- 错题太多，不知道考前该复习哪几道。
- 家长没时间帮孩子整理错题。
- 孩子总在同一类题上反复错。
- 每次考试前才发现错题没复盘。
- 做过的题没有沉淀，下次还是不会。
- 想找能体现错题上传、错因分析、复习闭环的图。

语义总结匹配信号：

- 画面包含试卷、练习册、错题、红叉、手机上传、错题列表。
- 手机或电脑界面展示错题本、错因分析、复习提醒、相似题、同类题。
- 摘要提到“上传错题”“整理错题”“归档错题”“错题复习”“同类题推荐”。

排除/降权信号：

- 只是普通做题页面，没有错题沉淀。
- 只是单题讲解，没有错题本、错因分析或复习闭环。
- 只是泛学习、泛练习、泛课程。

评测 query：

- 错题本
- 体现能够上传错题的
- 拒绝题海战，整理错题太费时间还容易忘
- 孩子这道题会了，换个题型还是错
- 考前想复习以前错过的题

### 3.2 AI拍题精学

核心标签：`同步自学体系 > AI拍题精学`  
原文档核心卖点：拍题不是直接给答案，而是识别题目、分步讲解、引导思路，帮助孩子真正学会。

用户常见话术：

- 拍题
- 拍题精学
- 拍题讲解
- 拍照搜题
- 拍题分步讲解
- 题目识别
- 解题思路
- 一拍就学
- 不直接给答案
- 苏格拉底式提问

家长痛点表达：

- 家长怕孩子拿手机拍题只是抄答案。
- 孩子十分钟写完作业去玩，考试就露馅。
- 不想让拍题变成偷懒工具。
- 孩子看了答案但没真正理解。
- 拍完题要讲思路，而不是只给最终答案。
- 作业靠搜答案完成，换个题还是不会。
- 家长不知道孩子是真懂了还是背下来了。
- 希望 AI 像老师一样一步步追问启发。
- 想找表现拍题后分步讲解的图片。

语义总结匹配信号：

- 画面有相机取景框、拍题按钮、题目识别、手机拍摄题目。
- 界面展示分步讲解、解题思路、引导提问、动画课补充讲解。
- 摘要提到“不是直接给答案”“先讲思路”“一步步引导”“分步解析”。

排除/降权信号：

- 只展示最终答案。
- 只是普通 AI 答疑聊天，没有拍题或题目识别。
- 只是错题本列表，没有拍题讲解过程。

评测 query：

- 拍题
- 体现拍题精学
- 家长怕孩子拿手机拍题只是抄答案
- 拍题后要讲思路，不是直接给答案
- 孩子拍题写作业很快，但考试不会

### 3.3 AI私教答疑

核心标签：`同步自学体系 > AI私教答疑`  
原文档核心卖点：孩子学习过程中随时唤醒 AI 私教，有问题随时问，具体问题具体解决，降低家长辅导压力。

用户常见话术：

- AI私教
- AI答疑
- 随时问
- 智能辅导
- AI老师
- 问题不过夜
- 学习卡住有人帮
- 家长不会辅导

家长痛点表达：

- 孩子遇到问题没人讲。
- 家长不会教，讲了还容易吵。
- 晚上写作业卡住，不知道问谁。
- 不想让问题拖到第二天。
- 孩子不好意思问老师。
- 家长辅导不了初中数学。
- 需要一个随时能问的学习助手。

语义总结匹配信号：

- 画面有 AI 对话、提问框、智能答疑、互动辅导。
- 摘要提到“随时提问”“AI 解答”“互动式辅导”“问题不过夜”。

排除/降权信号：

- 真人老师督学消息应优先归入真人老师督学。
- 只有课程视频，没有问答互动。

评测 query：

- 孩子晚上写题卡住没人教
- 家长不会辅导初中题
- 想找 AI 随时答疑的图

### 3.4 极速预习复习

核心标签：`同步自学体系 > 极速预习复习`  
原文档核心卖点：课前拍一拍课本，快速理清头绪；作业前拍笔记，快速回顾重点，提高效率。

用户常见话术：

- 极速预习
- 极速复习
- 课前预习
- 课后复习
- 五分钟预习
- 知识点速览
- 快速回顾
- 考前快速过一遍

家长痛点表达：

- 孩子上课前完全没准备。
- 明天要上新课，今晚想快速预习。
- 作业前忘了今天学的内容。
- 时间很少，但想快速抓重点。
- 考前来不及系统复习。
- 孩子学完就忘，需要快速回顾。

语义总结匹配信号：

- 画面有课本、笔记、知识点总结、预习/复习按钮。
- 摘要提到“课前”“课后”“快速梳理”“知识点回顾”“五分钟”。

排除/降权信号：

- 长期学习规划不应误归入极速预习复习。
- 只有完整课程讲解而没有预习/复习时序。

评测 query：

- 上课前快速预习一下
- 作业前想回顾今天知识点
- 考前没时间了，想快速复习

## 4. 同步伴学体系

### 4.1 真人老师督学

核心标签：`同步伴学体系 > 真人老师督学`  
原文档核心卖点：真人老师伴学，帮助分析问题、制定计划、定期督促并主动反馈，替家长接管难管的部分。

用户常见话术：

- 真人老师督学
- 真人老师伴学
- 督学老师
- 学习监督
- 老师提醒
- 人工跟进
- 老师盯学
- 作业催促

家长痛点表达：

- 孩子叫不动、管不住。
- 一管孩子就吵架。
- 家长每天催作业太崩溃。
- 孩子自律差，需要有人盯。
- 家长不想天天盯学习。
- 想找有人帮家长监督孩子的图。
- 需要老师定期跟进、提醒和反馈。
- 家长辅导孩子时最崩溃的不是题难，而是孩子不配合。

语义总结匹配信号：

- 画面有真人老师、老师消息、督促提醒、人工反馈、跟进记录。
- 摘要提到“老师督促”“定期跟进”“主动反馈”“替家长管学习”。

排除/降权信号：

- AI 对话不等于真人老师督学。
- 只有学习报告，没有老师提醒或人工跟进。

评测 query：

- 孩子叫不动管不住，一管就吵架
- 家长不想每天催孩子学习
- 需要真人老师帮忙监督

### 4.2 学情报告反馈

核心标签：`同步伴学体系 > 学情报告反馈`  
原文档核心卖点：家长每晚或每周看到学习报告，知道孩子学了什么、学了多久、掌握情况如何，减少黑盒焦虑。

用户常见话术：

- 学情报告
- 学习周报
- 学习反馈
- 家长报告
- 学习数据
- 学习情况透明
- 进度反馈
- 正确率报告

家长痛点表达：

- 不知道孩子今天到底学了没。
- 孩子学了啥、学了多久，家长完全不知道。
- 家长只想看一眼报告就放心。
- 学习过程像黑盒，心里没底。
- 想知道孩子哪些知识点没掌握。
- 希望每天收到学习反馈。
- 不想一直坐旁边盯着。

语义总结匹配信号：

- 画面有学习报告、周报、正确率、学习时长、掌握情况、进度条。
- 摘要提到“家长查看报告”“学习状态反馈”“薄弱点统计”。

排除/降权信号：

- 只有一次小测结果，没有综合报告。
- 只有老师消息，没有报告或数据。

评测 query：

- 家长想知道孩子每天学了什么
- 学习过程不是黑盒
- 每周给家长发学习报告

## 5. 同步规划体系

### 5.1 AI定制学习方案

核心标签：`同步规划体系 > AI定制学习方案`  
原文档核心卖点：根据孩子真实情况、年级、学科、目标、考试、成绩水平、教材版本和学习时间，制定量身定制的学习计划。

用户常见话术：

- AI定制班
- AI定制学习方案
- 个性化学习方案
- 私人学习计划
- 学习路径
- 学习日程
- 精准匹配
- 不知道学什么
- 省心安排

家长痛点表达：

- 家长不知道该让孩子先学什么。
- 离考试还有 30 天，不知道怎么安排。
- 孩子基础一般，后面该补什么。
- 买了很多课但不知道哪个适合。
- 报班怕不匹配，浪费钱和时间。
- 每天晚上都要问孩子今天学什么。
- 作业太多，孩子不知道先做哪一项。
- 学习没有方向，越学越乱。
- 家长不是教育专家，不会做学习规划。
- 想找能体现按孩子情况定制学习路径的图。

语义总结匹配信号：

- 画面有学习计划、日程、目标、年级学科、教材版本、学习周期、任务列表。
- 摘要提到“根据真实成绩/目标/考试时间定制”“学习路径规划”“每日任务安排”。

排除/降权信号：

- 专家规划强调专家背书，AI定制学习方案强调个体条件和计划生成。
- 普通课程列表不等于定制方案。

评测 query：

- 不知道孩子接下来该学什么
- 离中考还有一个月怎么规划
- 想按孩子水平定制学习计划
- 家长不用每天安排学习任务

## 6. 同步培养体系

### 6.1 专家规划

核心标签：`同步培养体系 > 专家规划`  
原文档核心卖点：课程由中高考命题专家、教材编者、教研团队参与设计，知道考试方向，让孩子学习不走弯路。

用户常见话术：

- 专家规划
- 命题专家设计
- 教研专家
- 教材编者
- 出题人视角
- 专家课程
- 专家把关
- 课程体系设计

家长痛点表达：

- 外面的班课像盲人摸象，什么都教。
- 真正出考卷、编课本的人设计课程。
- 知道三年后的中考考什么。
- 孩子现在每一分钟都在为考试拿分做准备。
- 不想让孩子学一堆无效内容。
- 希望课程方向有人把关。
- 想找能体现专家设计学习路径的图。
- 不是普通老师讲课，而是有命题和教研视角。

语义总结匹配信号：

- 画面有专家、教研、命题人、教材编写、课程体系、学习路径设计。
- 摘要提到“专家设计”“命题视角”“教材编者”“中考方向”“不走弯路”。

排除/降权信号：

- 普通新课标、新考法不等于专家规划。
- 只有课程页面但没有专家、规划或专业背书。

评测 query：

- 专家规划
- 体现专家规划
- 出卷人和编教材的人设计课程
- 孩子学习不走弯路
- 每一分钟都为中考拿分做准备

## 9. 语义总结参与搜索的建议

### 9.1 图片侧语义画像

每张图片可组合以下字段形成检索文本：

```text
标题
主体系与二级标签
人工标签
AI业务标签及理由
image_summary
content_tags
recommended_search_words
negative_tags
```

其中 `image_summary` 应尽量写出：

- 画面主体：谁在做什么。
- 功能界面：页面展示了什么功能。
- 业务卖点：它体现的是上传错题、分步讲解、专家规划，还是学情反馈。
- 排除信息：它不是普通课程、不是只给答案、不是泛学习场景。

### 9.2 查询侧意图画像

智能搜索理解 query 时，建议输出：

```json
{
  "primary_intent": "AI错题本",
  "target_label": "sync_self_study > ai_error_book",
  "pain_points": ["整理错题麻烦", "错题容易遗忘", "换题型还错"],
  "must_have_concepts": ["错题上传", "错题整理", "错因分析"],
  "nice_to_have_concepts": ["同类题训练", "复习提醒"],
  "exclude_concepts": ["普通课程", "只给答案", "泛学习场景"],
  "result_policy": "strong_intent_allow_few_results"
}
```

### 9.3 排序建议

当 `primary_intent` 命中明确二级标签时：

- 直接命中目标标签：强加权。
- `image_summary` 命中 must-have concept：强加权。
- 命中排除项：降权或移出主结果。
- C 级兜底不得排在 S/A/B 级结果前。
- 若强相关不足，不强行补满。

## 10. 当前优先修复的三个意图簇

根据 2026-06-28 手工测试，优先用以下三个簇做第一批搜索评测和优化：

1. `同步自学体系 > AI错题本`
   - 问题：错题痛点长文案没有稳定归一到 AI 错题本。
   - 典型 query：整理日常练习册上的错题既耽误功夫又容易遗忘。

2. `同步自学体系 > AI拍题精学`
   - 问题：家长担心“拍题抄答案”的表达没有稳定归一到拍题精学。
   - 典型 query：家长怕孩子拿手机拍题，只为了十分钟写完作业去玩。

3. `同步培养体系 > 专家规划`
   - 问题：业务文案能识别出专家规划标签，但结果仍被 C 级兜底污染。
   - 典型 query：外面的班课是在盲人摸象，真正出考卷、编课本的人设计课程。

这三类问题的共同定义：

> 自然语言业务话术没有稳定归一到核心业务标签，且搜索结果没有围绕强意图收紧，导致精准素材被泛学习兜底结果稀释。
