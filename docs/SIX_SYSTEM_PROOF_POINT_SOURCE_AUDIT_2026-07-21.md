## 判定标准

1. **稳定证明点**：可长期回答“凭什么相信这个卖点”，有明确对象、机制、流程、产品能力或证据类型。
2. **证据样例**：人物、学校、课例、数字、媒体文章、用户反馈和具体页面，可替换、可增删，默认不升格为固定证明点。
3. **待核验事实**：数字、身份、奖项、学校、效果、服务政策和可能随版本变化的产品字段，必须保留来源、时间与口径。
4. **绿色分支**：原图中的图片制作或寻找建议，不是已有事实、已有素材、标签或证明点。
5. **素材准入**：证明点只在已确认父卖点的人工 accepted `expresses/supports` 候选内精排；缺少对应素材时允许返回空。

## 关键纠偏

- Cursor 提到的“13 个教材版本”清单确实存在，但位于 `01-sync-school.png`；同步校内文件此前已经完整写入 13 个版本，本轮没有重复添加到同步考点。
- 原图细节缺失不等于必须新增证明点。专项模块名、学校、数字、媒体和用户反馈均可在既有稳定证明点下作为证据样例管理。
- “AI 拍题五步引导”既能支撑同步考点的原理迁移，也属于同步自学拍题精学的主流程；运行时仍按查询主动作和父卖点边界决定，不因证据复用复制新卖点。
- 56 个证明点已覆盖七张原图的稳定论断，本轮保持 code 和父卖点归属不变。
- 真实页面查询“错题后再练3-5道同类题”曾只形成父卖点弱候选，证明“证明点话术存在”并不自动保证父卖点先被识别；现用 Skill 内部自然语言信号补齐父卖点入口，不增加数据库公共话术。修复后链路稳定落到 `ai_error_book > pp_selfstudy_error_variant_recommendation`。
