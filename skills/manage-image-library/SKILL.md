# 管理图片素材库

把素材组视为业务语义主体，把图片视为主图、延展尺寸、备选或历史版本。执行前完整读取 `RULES.md`；涉及业务卖点时同时使用 `understand-image-search-intent` 的稳定 code 和关系边界。

## 工作流

1. 上传前校验格式、大小、像素和安全文件名；图片字节只进入配置的存储根目录。
2. 首次上传创建素材组和主图。卖点不是上传必填项，用户填写的素材话术保持可编辑。
3. 正式主图可触发 `analyze-image-asset`；尺寸/渠道延展不触发 AI，并继承素材组语义。
4. 人工关系使用 `expresses`、`supports`、`excludes`，并与 AI `pending/accepted/rejected` 建议保持来源分离。
5. 主图替换保留素材组和人工事实，新图分析不得覆盖人工关系。
6. 普通删除进入回收站；素材组中的正式主图必须先替换，才能删除原版本。永久删除只从回收站执行。
7. 下载只解析受控 storage key，成功响应后再记录下载次数。

## 不变量

- 不恢复图片直挂固定标签树或“上传必须选体系”。
- 公共话术属于卖点层；当前素材独有话术属于素材组。
- AI 建议不能自动成为人工事实，搜索只承认规定的审核状态。
- 数据库提交与文件移动必须具备失败回滚和临时文件清理。
