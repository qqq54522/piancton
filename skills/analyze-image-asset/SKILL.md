# 图片素材分析

把单张正式主视觉转换成 Semantic Profile V3 和可审核的业务关系建议。执行模型任务前完整读取 `RULES.md`，并使用数据库当前启用卖点目录约束模型输出。

## 运行流程

1. 只处理主图、主图修订版或明确需要独立分析的备选图；`derivative` 尺寸/渠道延展直接继承素材组语义，不运行本 Skill。
2. 校验图片文件后，通过当前 `ModelProvider` 执行 `image_content_analysis`。
3. 先经过 normalizer，再经过 Pydantic schema 和当前启用业务概念 code 校验。
4. 保存语义总结和 Semantic Profile V3；业务概念关系和素材话术只能作为 AI 待审核建议保存。
5. 只有正式主图可以刷新素材组级 AI 建议、Embedding 和搜索派生索引。
6. 上传成功与分析成功分别记录；分析失败不得回滚已完成的安全上传，也不得覆盖上一次有效档案。

## 人工事实边界

- AI 只能建议 `expresses` 或 `supports`，不能生成正式人工关系。
- 人工 `accepted` 关系是搜索金标准；AI `pending` 建议不参与搜索。
- 已有同卖点人工 `accepted` 关系时，不再重复生成该卖点的待审核建议。
- 不生成或恢复 OCR、固定二级标签、`content_tags`、视觉风格、排除标签等已下线字段。
