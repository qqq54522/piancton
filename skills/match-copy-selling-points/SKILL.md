# 匹配文案卖点

这是兼容的文案运营匹配能力，与业务端图片搜索意图识别分开。执行模型任务前完整读取 `RULES.md`，并读取运行时附加的版本化文案点与目标核心卖点映射。

## 工作流

1. 接收活动、课程或营销文案原文，不自行补写营销事实。
2. 只从当前目录中的 `copy_point` code 选择候选，按体系分组并给出 0～1 权重。
3. 返回可用于后续召回的少量扩展词和整体置信度。
4. 经过 Pydantic schema 校验后返回；未知 code、错误结构或空白伪结果均视为失败。

## 边界

- 文案运营点可以映射到一个或多个稳定核心卖点，但不能创造新的六大体系或核心卖点。
- 本 Skill 不决定具体图片，也不能绕过人工 accepted 素材关系。
- 普通图片搜索继续使用 `understand-image-search-intent`，不能把本兼容接口的30个文案点当成图片固定标签树。
