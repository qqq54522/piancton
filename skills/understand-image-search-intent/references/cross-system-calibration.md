## 跨体系运行时校准摘要

- 先判断五个维度：**对象**（课本/题目/错题/学生过程）、**动作**（讲解/测试/规划/监督/汇总）、**时间尺度**（当前一题/一课/每天/每周/跨学段）、**目的**（听懂/确认掌握/迁移/执行/反馈）、**执行主体**（AI/系统/真人老师/专家）。共享词不能脱离这五项直接硬路由。
- “AI 拍照/拍一下”是同步自学四个卖点的探索入口；拍课本/笔记做课前课后速览归 `rapid_preview_review`，拍当前不会题分步推导归 `photo_guided_learning`，拍个人错题长期归档复练归 `ai_error_book`，文字/语音/图片随时互动问 AI 且没有专门拍题流程归 `ai_tutor_qa`。
- “拍题”不等于极速预习复习。缺少后续目的时在拍题精学、AI 答疑和 AI 错题本之间探索；只有出现课本/笔记与课前/课后短时梳理，才命中极速预习复习。
- “拍不会的题 → AI 先问步骤/讲思路 → 仍不懂再推知识点动画课”是拍题精学的连续流程，动画课是兜底证明点，不与同步校内动画精讲组成多卖点；独立要求动画讲透抽象知识时才归动画精讲。
- “理解原理/换题也会”缺少语境时在 `transfer_practice` 与 `universal_method` 之间待消歧；考试题型、变式和一道题会一类题归前者，长期思维、学科方法、摆脱死记和学习后劲归后者。
- “规划”必须区分主体和产物：命题/教材专家设计通用课程体系归 `expert_planning`；系统根据个人成绩、目标和时间生成接下来任务归 `ai_learning_plan`；真人老师诊断、制定并持续督促执行归 `human_teacher_supervision`。
- “反馈/正确率/掌握情况”必须看时间尺度：学完当前一课马上练测归 `instant_quiz`；按日/周汇总内容、时长、正确率和薄弱点给家长归 `learning_report`；真人老师主动提醒、回访和管理归 `human_teacher_supervision`。
- “随时能看到学习成果”只有结果可见、没有练测动作或周期报告证据时，在 `instant_quiz` 与 `learning_report` 之间保持探索。卖点候选可以并列，但图片层只保留直接呈现成果/报告的素材，不把题库、错题归纳、普通练题流程一起放行。
- “快速复习”必须看对象：校内教材章节对应归 `school_sync`，课前课后拍课本/笔记短时梳理归 `rapid_preview_review`，个人历史错题复盘归 `ai_error_book`，考前重难点/压轴题集中突破归 `focused_excellence`。
- “家长省心/放心”是 `ai_learning_plan`、`human_teacher_supervision`、`learning_report` 的共享结果，只能作为探索入口；只有“有人管”通常偏真人督学，但单独出现仍不能推断套餐、频率或服务形式。
- 真多卖点要求每个卖点都有独立证据；同一个共享词映射多个卖点是探索或待消歧，不是真多卖点。显式否定进入 `excluded_concepts`，不得同时作为正向证据。

## 统一判别维度

按以下顺序判断，不先猜体系：

1. **对象**：正在处理的是教材章节、抽象知识点、一道当前题、个人错题、考试题型、学生日程还是学习过程数据。
2. **动作**：同步、讲透、练测、专项训练、生成计划、即时答疑、真人督促、长期归档或周期汇总。
3. **时间尺度**：当前一题、一课结束、课前课后、每天任务、每周报告、升学阶段或长期能力。
4. **目的**：听懂知识、确认掌握、针对考试、迁移方法、开始执行、持续自律或让家长看清结果。
5. **执行主体**：AI 即时互动、系统自动规划、真人老师管理、命题/教材专家设计，不能只用“老师/规划/反馈”等泛词代替。

两个候选若共享对象或动作，优先用时间尺度和目的消歧；仍缺少证据时保持待消歧。

## 16 个卖点最小充分证据

| 稳定 code | 最小充分证据 | 不能单独作为证据 |
|---|---|---|
| `school_sync` | 教材版本、课程目录或章节进度与学校对应 | 复习、跟不上 |
| `animation_explanation` | 用动画/故事/可视化讲透抽象知识点 | 动画风格、讲解 |
| `instant_quiz` | 学完当前内容立即练习或检测掌握 | 正确率、反馈 |
| `new_curriculum_prediction` | 新课标/新中高考改革带来的新题型、新情境或跨学科考法 | 新教材、预测、提分 |
| `focused_excellence` | 明确学科重难点、压轴题、高频失分点或考前专项突破 | 薄弱、练习、重点 |
| `transfer_practice` | 考试题型/变式语境下，一题带一类题并能迁移 | 理解原理、换题也会 |
| `expert_planning` | 命题专家、教材编者或教研专家设计课程体系和长期路径 | 名师、规划、不走弯路 |
| `stage_transition` | 小升初/初升高/小初高连续覆盖及知识断层过渡 | 升学、跟进度、拔高 |
| `universal_method` | 摆脱死记、形成学科思维和长期自主分析能力 | 底层逻辑、理解原理 |
| `ai_learning_plan` | 结合个人成绩/目标/时间生成接下来学什么、先后顺序或每日任务 | 省心、规划、学习方案 |
| `ai_tutor_qa` | 学习中可随时用文字/语音/图片与 AI 即时互动答疑 | AI、拍题、点拨思路 |
| `photo_guided_learning` | 拍当前不会题，不直接给答案并分步引导推导 | 拍题、AI 拍照 |
| `rapid_preview_review` | 课前/课后拍课本或笔记做短时间预习复习 | 快速复习、拍一下 |
| `ai_error_book` | 把个人线下错题长期归档、查询并从错题出发复练 | 同类题、拍题、错题 |
| `human_teacher_supervision` | 真人老师持续诊断、提醒、打卡、回访并跟进执行 | 有人管、老师反馈、省心 |
| `learning_report` | 按日/周汇总学习内容、时长、行为、正确率或薄弱点给家长 | 反馈、正确率、掌握情况 |

## 共享入口与相邻边界

| 共享表达 | 候选 | 决胜证据 |
|---|---|---|
| AI 拍照、拍一下 | 自学四卖点 | 课本/笔记短时梳理；当前题分步推导；个人错题归档；一般即时互动 |
| 拍题 | 拍题精学 / AI 答疑 / AI 错题本 | 当前题专门流程；一般问答；保存到个人错题库 |
| 预习、复习 | 校内同步 / 极速预习复习 / AI 错题本 / 专项培优 | 教材章节；课前课后拍摄速览；个人历史错题；考前重难点 |
| 理解原理、换题也会 | 举一反三 / 底层方法 | 考试题型变式；长期学科思维 |
| 规划、学习路径 | 专家设计 / AI 学习计划 / 真人督学 | 通用课程设计；个人自动日程；真人持续执行管理 |
| 反馈、正确率、掌握 | 学练测 / 学情报告 / 真人督学 | 当前一课即时检测；周期结构化汇总；真人主动管理沟通 |
| 随时看到学习成果 | 学练测 / 学情报告 | 当前一课的结果反馈；周期或家长端成果报告；没有时间尺度时共同探索，再由图片话术筛选 |
| 错题、同类题 | AI 错题本 / 专项培优 / 举一反三 | 个人历史错题；群体高频失分点；考试题型迁移 |
| 跟不上 | 校内同步 / 动画讲解 / 学段衔接 | 版本进度；课堂没听懂；升学知识断层 |
| 家长省心 | AI 规划 / 真人督学 / 学情报告 | 自动安排；真人管过程；家长看结果 |

## 多卖点、探索、歧义和否定

- **明确多卖点**：每个卖点至少有一组不与其他卖点共用的证据。例如“系统按成绩排每天任务，再由真人老师监督打卡”。
- **探索型**：只给共享入口或体系名，用户尚未说明目的。例如“AI 拍照”“家长省心”“同步自学素材”。
- **待消歧**：已有相邻候选，但句子仍无法区分。例如“理解原理，换题也会”“老师定期反馈孩子情况”。
- **否定**：只排除被明确否定的稳定卖点；“不要直接给答案”是拍题精学的正向机制，不存在“直接给答案”卖点，不制造排除 code。
- **宽泛结果**：“提分、有效、省心、学习好、后劲足”没有能力、对象或场景证据时，不产生可信卖点。

## 校准评测原则

1. 每个稳定卖点至少保留一条跨体系边界明确的正例。
2. 共享入口同时覆盖探索或待消歧用例，防止把一个词误判成真多卖点。
3. 高风险相邻对同时保留两侧正例，不能只证明其中一侧会识别。
4. 多卖点用例必须能给每个卖点划出独立原文证据。
5. 否定用例同时检查正向命中和 `excluded_concepts`，防止否定词反向召回。
6. 评测只验证体系/卖点识别；图片结果仍必须通过 accepted `expresses`/`supports` 关系，不在评测文本里假设素材已存在。
