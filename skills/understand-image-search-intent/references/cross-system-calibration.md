## 跨体系运行时校准摘要

- 先判断五个维度：**对象**（课本/题目/错题/学生过程）、**动作**（讲解/测试/规划/监督/汇总）、**时间尺度**（当前一题/一课/每天/每周/跨学段）、**目的**（听懂/确认掌握/迁移/执行/反馈）、**执行主体**（AI/系统/真人老师/专家）。共享词不能脱离这五项直接硬路由。
- “AI 拍照/拍一下”是同步自学四个卖点的探索入口；拍课本/笔记做课前课后速览归 `rapid_preview_review`，拍当前不会题分步推导归 `photo_guided_learning`，拍个人错题长期归档复练归 `ai_error_book`，文字/语音/图片随时互动问 AI 且没有专门拍题流程归 `ai_tutor_qa`。
- “教材同步/版本适配/人教版/北师大版/多教材版本/全国教材适配”必须看对象是否是学校教材版本或课程目录：教材版本对象与同步、适配、覆盖、跟学校进度学、不同地区都能用等目的组合出现时归 `school_sync` 的教材版本覆盖证明点；若说新课标、新题型、新考法或跨学科变化，归 `new_curriculum_prediction`；若说系统按个人成绩目标排每天任务，归 `ai_learning_plan`。
- “新课标/新中考/新高考/新考法”必须看动作：问考试改革、命题趋势、怎么考和新旧题型区别，归 `new_curriculum_prediction` 的课标改革与命题趋势拆解；问新题型、新情境、跨学科和开放探究怎么练，归同卖点的新题型课程与配套训练。教材版本、学校进度和地区教材覆盖仍归 `school_sync`；泛化重难点、压轴和考前冲刺仍归 `focused_excellence`。
- “拍题”不等于极速预习复习。缺少后续目的时在拍题精学、AI 答疑和 AI 错题本之间探索；只有出现课本/笔记与课前/课后短时梳理，才命中极速预习复习。
- “拍题精学/AI 拍题/拍照讲题/拍题讲解/AI 辅导题目/拍一道学一道/整页拍题”指向当前题讲解与知识点学习时归 `photo_guided_learning` 主流程；“拍题不是只给答案/AI 一步步讲题/拍题后还能追问/区别于普通搜题软件/从搜答案到学会/AI 拍题差异化/拍题核心价值”归 `photo_guided_learning` 的苏格拉底式提问和分步引导价值。若主要是随时文字语音问 AI，归 `ai_tutor_qa`；若主要是个人错题长期归档复练，归 `ai_error_book`。
- “AI 思维教练/思维教练/苏格拉底式教学/苏格拉底式引导/AI 引导思考/启发式学习/AI 追问/一步一步引导/培养解题思路/培养独立思考/让孩子自己想出答案/不是直接搜答案/从答案到思路/AI 互动教学/启发而不是灌输/真正的 AI 教学/会提问的 AI 老师/连续追问证明点”归 `photo_guided_learning` 的苏格拉底式提问和分步引导价值；这是 AI 拍题精学的方法证明，不新建“AI 思维教练”卖点。若表达只是“随时问 AI、AI 老师答疑、即时回答当前疑问”而没有启发、追问、引导思考证据，则归 `ai_tutor_qa`。
- “拍不会的题 → AI 先问步骤/讲思路 → 仍不懂再推知识点动画课”是拍题精学的连续流程，动画课是兜底证明点，不与同步校内动画精讲组成多卖点；独立要求动画讲透抽象知识时才归动画精讲。
- “动画精讲/动画讲解/老师讲太快听不懂/几分钟讲明白知识点”归 `animation_explanation` 的短时微课与教研方法证明点；“看不见的知识变成动画/抽象原理动画演示/变化过程可视化”归同卖点的分学科动画可视化证明点。“短时间”不能单独触发动画精讲，遇到“短时间高效复习”仍按复习对象和考试节点分流。
- “多少人在用/同学在用/学生教师共同选择/全国中小学生用户/用户规模/数据背书/数据图”归 `animation_explanation` 的官方数据规模证明点，用于承接 1.3 亿学生、400 万教师等品牌规模数据图。这里的“班上/同学”必须和在用、共同选择或数据背书组合才有效；不能因为“班”字误归 `ai_learning_plan` 的 AI 定制班。
- “课后小测/学完即练/学完即测/看完课马上做题/孩子说听懂了想马上看看会不会”归 `instant_quiz` 的学完即练闭环；按日/周汇总时长、正确率和薄弱点给家长归 `learning_report`，个人历史错题沉淀归 `ai_error_book`，专项考点刷题归 `focused_excellence`。
- “AI 私教答疑/随时问 AI/学习卡住可以问 AI/晚上没人辅导/家长不会辅导”归 `ai_tutor_qa` 的即时互动答疑；“会提问的 AI 老师/启发式提问/苏格拉底式引导/不直接给答案”归 `photo_guided_learning` 的苏格拉底式提问价值，不能被普通 AI 私教短词抢走。
- “练习册错题拍照上传/错题自动整理”归 `ai_error_book` 的线下错题拍照上传；“历史错题按知识点筛选复习/个人错题错因复盘”归错题分类复盘；“错题后再练同类题/从自己的错题推荐相似题”归个人错题后的同类题推荐。当前题讲完后的同类/变式训练归 `transfer_practice`，全网或群体高频错题归 `focused_excellence`。
- “极速预习/快速预习/课前预习/新课预习/提前学/上课前先学/课前快速过知识点/5 分钟或十分钟预习/轻量预习/快速了解新知识/明天课程提前看/先学再听课/提高课堂效率/带着问题进课堂/课前场景/预习效率/几分钟快速预习/上课之前先建立认知/提前知道课堂重点/新课学习前/每天晚上用/短时间完成预习”归 `rapid_preview_review` 的课前预习与课后复习双入口证明点；这是自学体系的课前预习侧，不新建“极速预习”单独卖点。若表达的是考试节点前复习冲刺，归 `focused_excellence`；若表达教材版本或学校进度适配，归 `school_sync`；若表达个人计划路径自动生成，归 `ai_learning_plan`。
- “极速复习/快速复习/课后复习/知识回顾/快速回顾/学完快速过一遍/5 分钟或十分钟复习/碎片化复习/快速巩固/轻量复习/当天知识当天复习/当天学当天复习/日常快速复习/快速查漏补缺/知识点快速回忆/学过内容重新过一遍/短时间复习/每天快速巩固/碎片时间学习/花很少时间复习/学习效率高/课后巩固/快速回顾重点”归 `rapid_preview_review` 的课前预习与课后复习双入口证明点中的课后复习侧，并下钻到极速复习证据表达点；这是日常/当天/学完后的短时回顾巩固，不新建“极速复习”单独卖点。若表达的是“明天月考快速复习、期末前三天冲刺”等考试节点前冲刺复习，归 `focused_excellence`；若表达个人错题长期归档复练，归 `ai_error_book`；若表达教材版本、课程目录或学校进度适配，归 `school_sync`。
- `transfer_practice` 与 `universal_method` 按题目对象直接分流：一道题讲完后继续做相似题、同类题或变式题归举一反三；同一道题使用不同方法或路径求解归万能解法。AI 拍题精学讲完当前题后自动推送相似题时，可同时形成 `photo_guided_learning` + `transfer_practice`，前者是当前题讲解，后者是后续迁移训练。
- `transfer_practice` 内部再按“为什么会一类题”分流：问出题原理、底层逻辑、不背模板和换问法也会，归先理解原理；问当前题讲完后推荐同类题、相似题、变式题或换数字/换条件继续练，归变式迁移训练。个人错题后的同类题复练归 `ai_error_book`；同一道题多种解法归 `universal_method`。
- 高频错题与 AI 错题本按数据对象分流：从全网题库或群体作答收集的共性高频错题归 `focused_excellence`；这个学生自己做错并长期保存、复练的题归 `ai_error_book`。
- “规划”必须区分主体和产物：命题/教材专家设计通用课程体系归 `expert_planning`；系统根据个人成绩、目标和时间生成接下来任务归 `ai_learning_plan`；真人老师诊断、制定并持续督促执行归 `human_teacher_supervision`。
- “专家/课程体系/长期路径”必须区分通用教研与个人定制：命题专家、教材编者、出题人或教研专家参与课程设计，归 `expert_planning`；课程体系、长期学习路径、课程顺序和能力进阶由专家把关，也归 `expert_planning`。根据这个孩子的成绩、薄弱点、可用时间自动生成每日任务或专属课程，归 `ai_learning_plan`。
- “小升初/初升高/小初高/全学段”必须区分升学节点与连续覆盖：某个升学节点、知识断层、新学段适应、衔接课或过渡课程归 `stage_transition` 的关键升学阶段衔接课程；小初高一体化、从小学到高中、12 年路径、全学段覆盖、不用换体系持续学，归同卖点的小初高连续课程体系。教材版本和学校进度不因此改归学段衔接。
- “万能解法/底层方法/学科思维”必须看题目对象：同一道题不同方法、不同路径、一题多解和从条件推结论，归 `universal_method` 的多路径拆解；不死记硬背、套公式撑不住、建立理科思维、长期后劲和陌生题没思路，归同卖点的迁移思维长期基础。当前题讲完后做同类/变式题仍归 `transfer_practice`。
- “AI 定制班/定制班/个性化学习/千人千面/个性化课程/因材施教/AI 定制学习/专属学习方案/个性化学习路径/根据水平安排课程/根据薄弱点推荐内容/学习计划自动生成/不同学生学不同内容/AI 规划学习路径/个性化教学/动态调整学习计划/每个孩子都有自己的学习方案/AI 个性化推荐/不同基础匹配不同内容/不是所有孩子学一套/专属课程方案/AI 根据学习情况持续调整”归 `ai_learning_plan` 的专属路径与每日任务结果。若只说薄弱题型专项训练、精准补弱或重难点拔高，归 `focused_excellence`；若只说教材版本或校内进度一致，归 `school_sync`；若真人老师制定并持续督促，归 `human_teacher_supervision`；若只是过去学习结果反馈，归 `learning_report`。
- “反馈/正确率/掌握情况”必须看时间尺度：学完当前一课马上练测归 `instant_quiz`；按日/周汇总内容、时长、正确率和薄弱点给家长归 `learning_report`；真人老师主动提醒、回访和管理归 `human_teacher_supervision`。
- “真人老师/督学/周报/反馈”必须区分过程管理与结果查看：真人老师分析问题、诊断和阶段规划归 `human_teacher_supervision` 的诊断计划；真人老师每天提醒、打卡、回访、跟进和错题复盘归持续督促。学习周报、学情报告、学了什么、学了多久、正确率和薄弱点归 `learning_report` 的核心指标；快进/倍速/开小差归报告行为线索；微信、小程序、家长端和每周推送归报告交付。
- “随时能看到学习成果”只有结果可见、没有练测动作或周期报告证据时，在 `instant_quiz` 与 `learning_report` 之间保持探索。卖点候选可以并列，但图片层只保留直接呈现成果/报告的素材，不把题库、错题归纳、普通练题流程一起放行。
- “快速复习”必须看对象和时间目的：校内教材章节对应归 `school_sync`，课前课后拍课本/笔记短时梳理归 `rapid_preview_review`，个人历史错题复盘归 `ai_error_book`；考试节点或临考时间与冲刺复习、抓重点、考前传播目的组合出现时归 `focused_excellence` 的考试阶段重点梳理，完整长句不逐句写入公共话术。
- “专项/题型/薄弱项训练”必须看对象和训练目的：题型、单项、薄弱题型、某类题或精准补弱与突破、强化、集中练等动作组合出现时归 `focused_excellence` 的按题型和薄弱点定向突破；一道题讲完后的同类题、相似题或变式题迁移归 `transfer_practice`；个人历史错题归档复练归 `ai_error_book`；群体高频错题归专项培优下的高频易错题证明点。
- “重难点/难题/优生/高分/高阶能力”必须看提升目的：与培优、拔高、突破、冲高分、继续提升、往满分冲等动作组合出现时，归 `focused_excellence` 的按题型和薄弱点定向突破；若表达的是升学断层或跨学段难度跃迁，归 `stage_transition`；若表达同一道题换多种解法，归 `universal_method`；若表达讲完当前题后继续做同类/变式题，归 `transfer_practice`。
- “家长省心/放心”是 `ai_learning_plan`、`human_teacher_supervision`、`learning_report` 的共享结果，只能作为探索入口；只有“有人管”通常偏真人督学，但单独出现仍不能推断套餐、频率或服务形式。
- 真多卖点要求每个卖点都有独立证据；同一个共享词映射多个卖点是探索或待消歧，不是真多卖点。显式否定进入 `excluded_concepts`，不得同时作为正向证据。

## 统一判别维度

按以下顺序判断，不先猜体系：

1. **对象**：正在处理的是教材章节、抽象知识点、一道当前题、个人错题、考试题型、学生日程还是学习过程数据。
2. **动作**：同步、讲透、练测、专项训练、生成计划、即时答疑、真人督促、长期归档或周期汇总。
3. **时间尺度**：当前一题、一课结束、课前课后、每天任务、每周报告、升学阶段或长期能力。
4. **目的**：听懂知识、确认掌握、针对考试、迁移方法、开始执行、持续自律或让家长看清结果。
5. **执行主体**：AI 即时互动、系统自动规划、真人老师管理、命题/教材专家设计，不能只用“老师/规划/反馈”等泛词代替。

两个候选若共享对象或动作，优先用时间尺度和目的消歧；仍缺少证据时保持待消歧。

## 16 个卖点最小充分证据

| 稳定 code | 最小充分证据 | 不能单独作为证据 |
|---|---|---|
| `school_sync` | 教材版本、课程目录或章节进度与学校对应 | 复习、跟不上 |
| `animation_explanation` | 用动画/故事/可视化讲透抽象知识点 | 动画风格、讲解 |
| `instant_quiz` | 学完当前内容立即练习或检测掌握 | 正确率、反馈 |
| `new_curriculum_prediction` | 新课标/新中高考改革带来的新题型、新情境或跨学科考法 | 新教材、预测、提分 |
| `focused_excellence` | 明确学科重难点、压轴题、高频失分点或考前专项突破 | 薄弱、练习、重点 |
| `transfer_practice` | 一道题讲完后继续推荐相似题、同类题或变式题 | 理解原理、单题讲解 |
| `expert_planning` | 命题专家、教材编者或教研专家设计课程体系和长期路径 | 名师、规划、不走弯路 |
| `stage_transition` | 小升初/初升高/小初高连续覆盖及知识断层过渡 | 升学、跟进度、拔高 |
| `universal_method` | 同一道题使用不同方法、不同路径求解 | 底层逻辑、理解原理 |
| `ai_learning_plan` | 结合个人成绩/目标/时间生成接下来学什么、先后顺序或每日任务 | 省心、规划、学习方案 |
| `ai_tutor_qa` | 学习中可随时用文字/语音/图片与 AI 即时互动答疑 | AI、拍题、点拨思路 |
| `photo_guided_learning` | 拍当前不会题，不直接给答案并分步引导推导 | 拍题、AI 拍照 |
| `rapid_preview_review` | 课前/课后拍课本或笔记做短时间预习复习；课后/学完后几分钟快速回顾重点、巩固当天知识或查漏补缺 | 快速复习、拍一下 |
| `ai_error_book` | 把个人线下错题长期归档、查询并从错题出发复练 | 同类题、拍题、错题 |
| `human_teacher_supervision` | 真人老师持续诊断、提醒、打卡、回访并跟进执行 | 有人管、老师反馈、省心 |
| `learning_report` | 按日/周汇总学习内容、时长、行为、正确率或薄弱点给家长 | 反馈、正确率、掌握情况 |

## 共享入口与相邻边界

## 多卖点、探索、歧义和否定

- **明确多卖点**：每个卖点至少有一组不与其他卖点共用的证据。例如“系统按成绩排每天任务，再由真人老师监督打卡”。
- **探索型**：只给共享入口或体系名，用户尚未说明目的。例如“AI 拍照”“家长省心”“同步自学素材”。
- **待消歧**：已有相邻候选，但句子仍无法区分。例如“理解原理，换题也会”“老师定期反馈孩子情况”。
- **否定**：只排除被明确否定的稳定卖点；“不要直接给答案”是拍题精学的正向机制，不存在“直接给答案”卖点，不制造排除 code。
- **宽泛结果**：“提分、有效、省心、学习好、后劲足”没有能力、对象或场景证据时，不产生可信卖点。

## 校准评测原则

1. 每个稳定卖点至少保留一条跨体系边界明确的正例。
2. 共享入口同时覆盖探索或待消歧用例，防止把一个词误判成真多卖点。
3. 高风险相邻对同时保留两侧正例，不能只证明其中一侧会识别。
4. 多卖点用例必须能给每个卖点划出独立原文证据。
5. 否定用例同时检查正向命中和 `excluded_concepts`，防止否定词反向召回。
6. 评测只验证体系/卖点识别；图片结果仍必须通过 accepted `expresses`/`supports` 关系，不在评测文本里假设素材已存在。
