# 上传前素材独有话术生成

用途：根据尚未发布的单张图片、素材名称和已选卖点，模拟业务人员为了找到这张图会输入什么，生成指定数量的中文搜索话术草稿。

## 输出协议

只返回以下 JSON，不要返回图片总结、标签、卖点建议或其他字段：

```json
{
  "phrases": ["找一张能体现某个明确业务诉求的图"]
}
```

## 生成步骤

1. 先读素材名称，判断设计师希望这张图主要传达的业务主题；名称不是普通文件名时，优先用它确定意图。
2. 再读已选主要卖点及其定义、常见表达、正向证据和排除边界；这是业务含义的硬约束，不得偏到相邻卖点。
3. 最后读图片，只提取能证明该业务主题的画面、文字或结构。图片用于让话术确实能找到这张素材，不是让你复述画面。
4. 把上述判断改写成“业务人员正在素材库里找图”的完整自然语言，重点模拟不了解标准卖点名称的业务小白。

## 生成规则

- 必须严格返回输入要求的数量，只允许 2～5 条，不能少也不能多。
- 每条必须是一句业务人员真的可能输入搜索框的完整需求。优先使用“找一张……的图”“想找……的素材”“有没有能体现……的图”“需要一张能说明……的图”等自然句式。
- 以业务诉求或想表达的结果为主语，以画面证据为支撑。不要把手机、页面、按钮、章节数字、OCR 文字等可见名词机械拼成图片说明。
- 如果输入提供已选主要卖点，每条都必须符合该卖点的业务定义和排除边界；不要创造新卖点，也不要仅复述卖点名或体系名。
- 生成数量不少于 3 条时，至少两条采用业务小白的口语或结果导向说法；其余可以是了解一点业务的人会说的功能、场景或痛点表达。
- 同一组话术应从结果、使用场景、痛点或图中特有证据等不同角度表达，但都要指向同一张图和同一已选卖点。
- 不得虚构图片中看不到的功能、数据、效果、客户、学校、证书或用户反馈。
- 不要返回“提分、学习不好、家长省心、效果很好”等没有画面对象和动作的宽泛结果。
- 不要重复同义句；每条不超过 80 个字符。
- 这些结果只是上传表单候选，用户可以编辑；不要宣称已经审核或已经写入素材库。

## 正反例

素材名称为“课程同步”、已选卖点为 `school_sync`，图片呈现手机课程章节与数学教材目录对应时：

- 正确：`找一张能体现和学校教材进度一致的图`
- 正确：`找一张学校学到哪，课程就讲到哪的图`
- 正确：`想找一张教材目录和课程目录能对应上的素材`
- 正确：`有没有课外课程不会和学校章节脱节的图`
- 正确：`找一张手机课程章节与数学课本目录同步的图`
- 错误：`手机章节切换界面对照八年级下册数学课本目录`（这是画面说明，不是业务搜索需求）
- 错误：`课程同步展示二次根式到勾股定理等教材章节`（机械复述 OCR 与章节名）
