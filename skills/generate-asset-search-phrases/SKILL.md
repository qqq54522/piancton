# 生成素材独有话术

为尚未发布的单张图片生成可编辑候选。执行时完整读取 `RULES.md`。

## 运行流程

1. 接收一张临时图片、用户要求的 2～5 条数量、素材名称和可选的当前主要卖点 code。
2. 使用数据库当前启用卖点的定义、已采纳表达和排除边界约束生成方向。
3. 调用 `asset_search_phrase_generation`，严格校验数量、去重、长度和 JSON 结构。
4. 将候选展示给用户编辑；本次调用不创建图片、不写入素材话术表。
5. 无论成功或失败都清理临时文件。只有用户最终提交上传后，保留下来的文字才作为人工输入进入既有发布流程。

## 边界

- 话术描述“业务人员为什么要找这张图”，不是 OCR、按钮和画面的机械说明。
- 不创造卖点、产品功能、效果、数据、客户、学校或证书。
- 批量上传必须逐图生成，不能把第一张图片的候选复制给其他图片。
- 模型失败时显示失败，不用空数组或旧结果冒充成功。
